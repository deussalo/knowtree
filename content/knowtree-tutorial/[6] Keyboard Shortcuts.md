# Keyboard Shortcuts

Knowtree provides keyboard shortcuts for fast navigation without reaching for the mouse. Press `Escape` to go back from the classroom to the graph view or from a graph to the selector, `F` to fit the graph to screen, and number keys to jump between panels. The tutor session itself runs in your terminal with all the standard Claude Code keybindings, so you get the full power of terminal editing while learning.
