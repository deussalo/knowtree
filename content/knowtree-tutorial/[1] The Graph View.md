# The Graph View

The graph view is a DAG visualization powered by D3.js and dagre that shows every topic in a knowledge graph as an interactive node. Nodes are colored by status — green for completed, blue for in-progress, orange for available, and grey for locked — and connected by directed edges that represent prerequisite relationships. You can click any available node to select it, double-click to fit the view, and use the sidebar to preview a node's content before diving in.
