# Node States and Progression

Every node in a knowledge graph moves through a lifecycle: locked, available, in_progress, and completed. A node starts locked until all its parent nodes are completed, at which point it becomes available. Starting a tutor session transitions it to in_progress, and passing the assessment marks it completed. This progression system ensures you build knowledge in the right order — each topic's prerequisites are genuinely mastered before you move on.
