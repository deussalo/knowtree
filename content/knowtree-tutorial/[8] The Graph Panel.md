# The Graph Panel

The graph panel is an interactive Plotly.js visualization area that the tutor can use to display charts, diagrams, and data plots alongside the classroom content. The tutor writes a JSON file (`active-plot.json`) with Plotly trace and layout data, and the webapp renders it as a fully interactive chart — zoomable, hoverable, and styled to match Knowtree's dark theme. This enables rich visual explanations of quantitative concepts, data flows, and system architectures.
