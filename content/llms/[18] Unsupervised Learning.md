# Unsupervised Learning

Unsupervised learning finds structure in unlabelled data — clustering, dimensionality reduction, density estimation. Language model pretraining is essentially unsupervised: the model learns the structure of language from raw text without explicit labels, making unsupervised learning the conceptual ancestor of the pretraining revolution.
