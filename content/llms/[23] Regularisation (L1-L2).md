# Regularisation (L1/L2)

Regularisation adds a penalty for model complexity to the loss function, preventing overfitting by discouraging large parameter values. L1 (lasso) encourages sparsity while L2 (ridge) encourages small weights — both concepts reappear in neural network weight decay and in understanding why dropout and other techniques help large models generalise.
