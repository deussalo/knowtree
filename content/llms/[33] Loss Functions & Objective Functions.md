# Loss Functions & Objective Functions

The loss function defines what the network is trying to optimise — cross-entropy for classification, MSE for regression, and variants for specific tasks. Understanding how the choice of loss function shapes what a model learns is critical because language model pretraining, fine-tuning, and RLHF each use different objectives that drive fundamentally different behaviours.
