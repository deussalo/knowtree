# Tokenisation in Practice — Vocabulary & Context Windows

The practical details of tokenisation — vocabulary size, special tokens, context window length, and how different languages are represented — directly affect model capability and efficiency. A model with a 4K context window versus 128K handles fundamentally different tasks. Understanding these constraints explains many real-world limitations and design choices in deployed LLMs.
