# Tool Use & Function Calling

Tool use extends LLMs beyond pure text generation by allowing them to invoke external functions — calculators, APIs, code interpreters, databases. The model learns to recognise when a tool is needed, generate the appropriate call, and incorporate the result. This capability transforms language models from knowledge retrievers into action-taking agents.
