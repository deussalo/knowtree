# Prompt Engineering & In-Context Learning

In-context learning is the remarkable ability of LLMs to learn new tasks from examples provided in the prompt, without any parameter updates. Prompt engineering — crafting inputs to elicit desired outputs — exploits this ability. Understanding why in-context learning works (and when it fails) is essential for effectively using language models and understanding the practical boundary between training and inference.
