# What is Machine Learning

Machine learning is the practice of building systems that learn patterns from data rather than following explicit instructions. Understanding the three paradigms — supervised, unsupervised, and reinforcement learning — and when each applies provides the conceptual framework for understanding how language models are trained, fine-tuned, and aligned.
