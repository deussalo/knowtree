# Multimodal Models (Vision-Language)

Multimodal models process and generate across multiple modalities — text, images, audio, video. Vision-language models like GPT-4V and Claude's vision encode images into the same representation space as text, enabling visual question answering, image description, and reasoning over visual content. Understanding multimodal architectures shows where LLMs are heading beyond text.
