# Autoencoders & Representation Learning

Autoencoders learn compressed representations by training a network to reconstruct its own input through a bottleneck. This forces the model to learn the most important features of the data. The concept of learned representations — as opposed to hand-engineered features — is the philosophical core of deep learning and directly underpins how language models learn meaningful representations of text.
