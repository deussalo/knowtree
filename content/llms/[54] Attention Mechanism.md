# Attention Mechanism

Attention allows a model to dynamically focus on relevant parts of the input when producing each output — instead of compressing everything into a fixed-length vector. By computing weighted sums over all positions based on learned relevance scores, attention solved the long-range dependency problem that plagued RNNs and became the defining operation of the transformer architecture.
