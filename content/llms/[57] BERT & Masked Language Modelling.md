# BERT & Masked Language Modelling

BERT (Bidirectional Encoder Representations from Transformers) introduced masked language modelling — predicting randomly masked tokens using both left and right context. This bidirectional pretraining produced representations that dramatically improved performance on understanding tasks like question answering and sentiment analysis, establishing the pretrain-then-fine-tune paradigm.
