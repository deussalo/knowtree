# Clustering (k-Means, Hierarchical)

Clustering groups similar data points without labels, revealing natural structure in data. k-Means partitions data into k groups by minimising within-cluster distance; hierarchical methods build tree-structured groupings. These techniques appear in understanding embedding spaces, topic modelling, and how LLMs implicitly learn to cluster semantically related concepts.
