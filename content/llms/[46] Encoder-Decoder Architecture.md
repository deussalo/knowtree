# Encoder-Decoder Architecture

The encoder-decoder framework separates understanding input (encoding) from generating output (decoding). The encoder builds a representation; the decoder consumes it to produce output token by token. This architecture is the direct ancestor of the transformer — BERT is an encoder, GPT is a decoder, and T5 uses both — making it essential context for understanding modern LLM design choices.
