# Evaluation & Benchmarks

Evaluating LLMs is notoriously difficult — benchmarks like MMLU, HumanEval, and GSM8K measure different capabilities, but benchmark saturation, data contamination, and the gap between benchmark performance and real-world usefulness create persistent challenges. Understanding evaluation methodology is essential for interpreting claims about model capabilities and for knowing what numbers actually mean.
