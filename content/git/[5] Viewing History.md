# Viewing History

Reading and navigating a project's commit history to understand what changed, when, and why. You will explore a real repository's log using `git log --oneline`, `--graph`, `--author`, and `--since` to filter and visualize the commit timeline. You will use `git diff` to compare the working tree, staging area, and specific commits, and `git show` to inspect individual commits in detail. Finally, you will use `git blame` on a specific file to trace each line back to the commit that last modified it, building a practical understanding of how to investigate code provenance.
