# Remote Repositories

Connecting your local repository to remote servers for backup, sharing, and collaboration. You will add a remote with `git remote add`, inspect it with `git remote -v`, and push your local branch with `git push -u origin main`. You will explore the difference between `git fetch` (download without merging) and `git pull` (fetch + merge), running each and comparing the results. Finally, you will configure upstream tracking branches, practice pushing and pulling between two local clones to simulate a multi-developer setup, and use `git remote show origin` to inspect the full remote configuration.
