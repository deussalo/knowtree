# Merging

Combining divergent branches back together and handling the conflicts that arise. You will perform a fast-forward merge by merging a branch that is strictly ahead of `main`, then create a situation where both branches have new commits to trigger a three-way merge with an automatic merge commit. Finally, you will deliberately create a merge conflict by editing the same line in the same file on two branches, then resolve it manually — editing the conflict markers, staging the resolved file, and completing the merge — so you are comfortable with the conflict resolution workflow.
