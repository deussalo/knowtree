# Merge Strategies

Advanced merging techniques for complex conflict scenarios. You will create a multi-file conflict situation and resolve it using `git checkout --ours` and `git checkout --theirs` on specific files to selectively accept one side's changes. You will configure and use a visual merge tool (like `vimdiff` or VS Code) via `git mergetool` to step through conflicts graphically. You will practice aborting a problematic merge with `git merge --abort` and retrying with a different strategy. Finally, you will explore Git's built-in merge strategies (`recursive`, `ort`, `octopus`) and understand when each is automatically selected.
