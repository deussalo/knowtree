# Collaboration & Pull Requests

Working with others through branches, forks, and code review workflows. You will fork a public repository on GitHub, clone your fork, create a feature branch, make changes, and push the branch to your fork. You will then open a pull request, write a clear description, and review the diff. You will practice updating a pull request by pushing additional commits to the same branch and observe how the PR updates automatically. Finally, you will review someone else's code changes (or your own from another branch), leave comments on specific lines, and understand the approve/request-changes/merge cycle.
