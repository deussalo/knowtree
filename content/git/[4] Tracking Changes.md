# Tracking Changes

The core Git workflow: staging, committing, and understanding file states. You will build a small project from scratch — creating files, using `git add` to stage them, and `git commit` to snapshot them — while running `git status` at every step to observe how files transition between untracked, modified, staged, and committed states. You will write a `.gitignore` file to exclude build artifacts and temporary files, testing it with `git status` to confirm the rules work. You will also practice partial staging with `git add -p` to commit only selected hunks from a modified file, learning to craft clean, atomic commits.
