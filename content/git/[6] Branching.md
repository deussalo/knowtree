# Branching

Creating, switching, and managing branches — Git's lightweight mechanism for parallel lines of development. You will create a feature branch with `git branch` and switch to it with `git switch`, make commits, and switch back to `main` to observe how your working tree changes. You will list all branches with `git branch -a`, rename a branch, and delete a fully-merged branch. Finally, you will simulate parallel work by making different commits on two branches and using `git log --oneline --graph --all` to visualize how the branches diverge, building intuition for how branching enables safe experimentation.
