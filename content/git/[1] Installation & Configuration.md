# Installation & Configuration

Getting Git running on your machine and tailoring it to your workflow. You will install Git on your operating system, verify the installation with `git --version`, and configure your identity with `git config --global user.name` and `user.email`. You will generate an SSH key pair, add the public key to a Git hosting service, and verify the connection with `ssh -T`. Finally, you will customize your environment by setting a preferred text editor, creating useful aliases (like `git lg` for a pretty log), and exploring the three config levels — system, global, and local — to understand how Git resolves configuration.
