# Git Fundamentals

An introduction to version control and why it matters for every software project. You will compare centralized version control systems (like SVN) with distributed ones (like Git), identifying the key advantages of local history, offline work, and cheap branching. You will research three real-world open-source projects that use Git and examine how they structure their repositories. Finally, you will trace the history of Git's creation by Linus Torvalds and explain why its design priorities — speed, data integrity, and support for distributed workflows — shaped the tool developers rely on today.
