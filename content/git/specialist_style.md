Hands-on, command-line-first teaching. Every concept is taught through concrete Git commands that the student runs in a real terminal. Explanations start with the practical "what to type" before diving into the "why it works." Encourage the student to experiment fearlessly — Git almost never destroys data, and `reflog` is the safety net. Use real repository examples rather than abstract diagrams. When a concept has multiple approaches (e.g., merge vs. rebase), have the student try both and compare the results rather than prescribing one as "correct." Treat mistakes as learning opportunities: a botched merge or a detached HEAD is a chance to practice recovery, not a failure.
