# Mastering Git

A capstone project that synthesizes everything you have learned into a realistic multi-developer simulation. You will manage a project with multiple feature branches developed in parallel, performing merges and rebases to keep branches up to date. You will create a release with proper tags and semantic versioning, then simulate a production hotfix that must be cherry-picked into both `main` and an active release branch. You will resolve complex merge conflicts, use `git bisect` to track down a regression, recover from a mistaken force-push using `reflog`, and stash work-in-progress while context-switching. The goal is a clean, well-organized repository history that demonstrates mastery of branching, merging, rebasing, tagging, and collaboration workflows.
