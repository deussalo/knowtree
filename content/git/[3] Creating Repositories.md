# Creating Repositories

Setting up new Git repositories and understanding what lives inside `.git/`. You will initialize a brand-new project from scratch with `git init`, create a few files, and make your first commit. You will then clone a public repository with `git clone` and compare the `.git/` directory structure of both — examining `HEAD`, `refs/`, `objects/`, and `config`. Finally, you will experiment with `git init --bare` to create a bare repository and explain when and why bare repos are used (such as for shared remotes on a server).
