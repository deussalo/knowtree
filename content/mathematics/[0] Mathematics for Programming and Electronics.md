# Mathematics for Programming & Electronics

This graph covers the applied mathematics foundation needed for programming and electronics work. Starting from arithmetic fundamentals, it branches through algebra, trigonometry, exponentials and logarithms, discrete mathematics, linear algebra, calculus, and probability. Each section builds on prior knowledge and emphasizes practical application over pure theory — you'll learn the math you actually need to write better code and understand circuits.
