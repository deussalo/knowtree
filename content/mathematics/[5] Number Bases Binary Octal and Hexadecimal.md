# Number Bases: Binary, Octal & Hexadecimal

How positional number systems work beyond base-10. Binary (base-2) is how computers store and process all data. Hexadecimal (base-16) is a compact way to represent binary values. Octal (base-8) appears in Unix file permissions and legacy systems. You'll learn to convert between bases and understand why these representations matter.
