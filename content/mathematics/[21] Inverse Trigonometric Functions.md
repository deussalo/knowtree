# Inverse Trigonometric Functions

arcsin, arccos, arctan — going from a ratio back to an angle. When you know the sides of a triangle and need the angle, or when you need to extract phase information from a signal, you use inverse trig functions. Understanding their domains and ranges (they can only return one value) is essential for correct usage in code and calculations.
